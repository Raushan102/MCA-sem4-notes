1Topic 1 of 52D TransformationsRED PRIORITY

Why RED? Direct evidence: 2D transformation operations appeared in MCA 2022–24 (CCMCA403) and 2D scaling in the older MCA paper (CS-DE-21). BCA papers add related questions on rotation, reflection, translation and shear.

1.1 Meaning of 2D Transformation

A 2D transformation is an operation that changes the position, size, orientation or shape of an object in a two-dimensional plane (X–Y plane). It is applied to the coordinates of the object's points to produce new coordinates.

For example, a rectangle can be moved to another location, enlarged, reduced, rotated, reflected or distorted using 2D transformations.

1.2 Types of 2D Transformations

The five basic transformations are translation, scaling, rotation, reflection and shearing.

1.3 Translation

Translation moves an object from one position to another without changing its size or orientation. Every point moves by the same distance in the same direction.

For a point P(x,y), translation by tx along the X-axis and ty along the Y-axis gives:

Translation equations

x' = x + tx

y' = y + ty

Here, tx and ty are the translation distances.

Example: Translate point P(2,3) by tx=4 and ty=2.

  • x' = 2 + 4 = 6
  • y' = 3 + 2 = 5

New point: P'(6,5).

1.4 Scaling

Scaling changes the size of an object. It may enlarge or reduce the object along the X and Y directions.

Scaling equations

x' = x × Sx

y' = y × Sy

Sx and Sy are the scaling factors along the X and Y axes.

  • If the scaling factor is greater than 1, the object becomes larger in that direction.
  • If the scaling factor is between 0 and 1, the object becomes smaller.
  • If the scaling factor is 1, there is no size change in that direction.

Example: Scale point P(3,4) using Sx=2 and Sy=3.

  • x' = 3 × 2 = 6
  • y' = 4 × 3 = 12

New point: P'(6,12).

1.5 Rotation

Rotation turns an object through a specified angle around a fixed point. In the basic case, the object is rotated around the origin.

Rotation equations about the origin

x' = xcosθ - ysinθ

y' = xsinθ + ycosθ

θ is the angle of rotation. A positive angle is counter-clockwise in the usual Cartesian coordinate system.

Rotation changes the orientation of the object, while its size and shape remain unchanged.

1.6 Reflection

Reflection produces a mirror image of an object about a selected line, such as the X-axis, Y-axis or origin.

Reflection aboutCoordinate transformation
X-axis(x',y')=(x,-y)
Y-axis(x',y')=(-x,y)
Origin(x',y')=(-x,-y)
Line y=x(x',y')=(y,x)

1.7 Shearing

Shearing slants the shape of an object. It shifts one coordinate in proportion to the other coordinate.

X-shear

x' = x + Shx × y

y' = y

Y-shear

x' = x

y' = y + Shy × x

Shx and Shy are the shear factors.

1.8 Comparison of Basic 2D Transformations

TransformationMain effectSize / shape
TranslationMoves an object.Unchanged
ScalingEnlarges or reduces an object.Size changes
RotationTurns an object by an angle.Unchanged
ReflectionCreates a mirror image.Size unchanged; orientation is reversed
ShearingSlants an object.Shape changes

Exam answer (5 marks)

2D transformation is the process of changing the position, size, orientation or shape of an object in the X–Y plane. The basic types are translation, scaling, rotation, reflection and shearing. Translation moves an object by adding fixed distances to its coordinates. Scaling changes its size using scaling factors. Rotation turns the object through an angle. Reflection creates its mirror image about an axis or line. Shearing slants the object by shifting its coordinates in proportion to the other coordinate. These transformations are used to manipulate graphical objects in computer graphics.

Why YELLOW? Related evidence: the broader MCA 2022–24 question “2D transformation operations”. No separate direct question on homogeneous coordinates or matrix representation is recorded.

2.1 Homogeneous Coordinates

In ordinary 2D Cartesian coordinates, a point is represented by two values: (x, y). In homogeneous coordinates, the same point is represented using three values: (X, Y, W).

For W not equal to zero, the Cartesian coordinates are obtained by dividing the first two values by W:

Conversion to Cartesian coordinates

x = X / W

y = Y / W

Example: homogeneous point (6, 9, 3) represents Cartesian point (2, 3).

A common way to represent Cartesian point (x, y) in homogeneous form is (x, y, 1).

2.2 Why Homogeneous Coordinates Are Used

  • They allow translation, scaling and rotation to be represented using matrices of the same size.
  • They make it easier to combine several transformations using matrix multiplication.
  • They provide a uniform mathematical representation for 2D transformations.

2.3 Matrix Representation

In homogeneous coordinates, a 2D point is written as a column vector:

Point vector

P = [ x ]

  [ y ]

  [ 1 ]

After transformation, the new point is obtained by multiplying the transformation matrix by the point vector:

General form

P' = T × P

P is the original point, T is the 3 × 3 transformation matrix, and P' is the transformed point.

2.4 Translation Matrix

Translation by tx along X and ty along Y is represented by:

Translation matrix

T = [ 1 0 tx ]

  [ 0 1 ty ]

  [ 0 0 1 ]

Example: Translate point (2, 3) by tx = 4 and ty = 2.

Calculation

P = [ 2 ]  T = [ 1 0 4 ]

  [ 3 ]    [ 0 1 2 ]

  [ 1 ]    [ 0 0 1 ]

P' = T × P = [ 6 ]

        [ 5 ]

        [ 1 ]

New point = (6, 5)

2.5 Scaling Matrix

Scaling by Sx along X and Sy along Y is represented by:

Scaling matrix

S = [ Sx 0  0 ]

  [ 0  Sy 0 ]

  [ 0  0  1 ]

The scaling factors determine how much the coordinates are enlarged or reduced.

2.6 Rotation Matrix

Rotation by angle θ around the origin is represented by:

Rotation matrix

R = [ cos(θ) −sin(θ) 0 ]

  [ sin(θ)  cos(θ) 0 ]

  [ 0     0    1 ]

For positive θ, the rotation is counter-clockwise in the usual Cartesian coordinate system.

2.7 Reflection and Shearing Matrices

Reflection about the X-axis and Y-axis can also be represented by 3 × 3 matrices:

Reflection about X-axis

Rx = [ 1  0 0 ]

  [ 0 −1 0 ]

  [ 0  0 1 ]

Reflection about Y-axis

Ry = [ −1 0 0 ]

  [ 0  1 0 ]

  [ 0  0 1 ]

X-shear and Y-shear matrices are:

X-shear

Shx = [ 1 Shx 0 ]

   [ 0  1  0 ]

   [ 0  0  1 ]

Y-shear

Shy = [ 1  0  0 ]

   [ Shy 1  0 ]

   [ 0  0  1 ]

2.8 Important Points to Remember

  • A 2D point uses two coordinates in Cartesian form and three values in homogeneous form.
  • The third homogeneous coordinate is commonly set to 1 for ordinary 2D points.
  • 2D transformation matrices in homogeneous coordinates are 3 × 3 matrices.
  • The transformed point is calculated using P' = T × P.
  • Matrix multiplication order matters when more than one transformation is applied. This will be covered in the next topic, Composition of 2D Transformation.

Exam answer (5 marks)

Homogeneous coordinates represent a 2D point using three values (X, Y, W), instead of the two Cartesian coordinates (x, y). When W is non-zero, x = X/W and y = Y/W. A Cartesian point (x, y) is commonly written as (x, y, 1) in homogeneous form. Homogeneous coordinates allow 2D transformations such as translation, scaling and rotation to be represented by 3 × 3 matrices. A point is transformed by multiplying its column vector by the transformation matrix: P' = T × P. This common matrix representation makes it easier to combine transformations.

3Topic 3 of 5Composition of 2D TransformationYELLOW PRIORITY

Why YELLOW? Related evidence: BCA papers contain composite-transformation questions, and the broader MCA 2D transformation question is related. No separate direct MCA question is recorded.

3.1 Meaning of Composition

Composition of 2D transformations means applying two or more transformations to an object, one after another. The transformations may include translation, scaling, rotation, reflection or shearing.

Instead of transforming every point separately after each operation, the individual transformation matrices can be multiplied to obtain one composite transformation matrix.

3.2 Composite Transformation Matrix

Using homogeneous column vectors, a point is transformed as P' = T × P. If T₁ is applied first and T₂ is applied second, then:

Combined transformation

P' = T₂ × (T₁ × P)

P' = (T₂ × T₁) × P

T = T₂ × T₁

Therefore, the rightmost matrix acts first.

For three transformations, if T₁ is applied first, then T₂, and finally T₃:

T = T₃ × T₂ × T₁

P' = T × P

3.3 Order of Transformations Matters

Matrix multiplication is generally not commutative. This means changing the order of two transformations can produce a different result:

T₂ × T₁ ≠ T₁ × T₂ (in general)

For example, translating an object and then scaling it may give a different final position from scaling it first and then translating it.

3.4 Solved Numerical Example

Consider the point P(1, 1). Apply a translation of (2, 0) and a scaling of (2, 2). Compare the two possible orders.

Case A: Translate first, then scale

After translation: (1 + 2, 1 + 0) = (3, 1).

After scaling: (3 × 2, 1 × 2) = (6, 2).

Matrix form

T = [ 1 0 2 ]

  [ 0 1 0 ]

  [ 0 0 1 ]

S = [ 2 0 0 ]

  [ 0 2 0 ]

  [ 0 0 1 ]

Composite matrix: S × T

Result for P(1,1): (6, 2)

Case B: Scale first, then translate

After scaling: (1 × 2, 1 × 2) = (2, 2).

After translation: (2 + 2, 2 + 0) = (4, 2).

Composite matrix: T × S

Result for P(1,1): (4, 2)

Conclusion: The two orders produce different results: (6, 2) and (4, 2). Hence, the order of transformations is important.

3.5 Advantages of Composite Transformation

  • Several transformations can be combined into one matrix.
  • The composite matrix can be calculated once and then applied to every point of an object.
  • It reduces repeated transformation calculations when many points are involved.
  • It makes complex object transformations easier to manage.

Exam answer (5 marks)

Composition of 2D transformation is the process of combining two or more transformations into a single composite transformation matrix. In homogeneous coordinates, a point is represented by a column vector P and transformed using P' = T × P. If T₁ is applied first and T₂ second, the composite matrix is T = T₂ × T₁. For more transformations, the matrices are multiplied in reverse order of application. Matrix multiplication is generally non-commutative, so the order of transformations affects the final result. Composite transformations reduce repeated calculations and make multiple transformations easier to apply.

4Topic 4 of 5Windows-to-Viewport TransformationRED PRIORITY

Why RED? Direct evidence: the older MCA paper (CS-DE-21) records a window-to-viewport transformation question.

4.1 Meaning

The window-to-viewport transformation is the process of mapping a selected part of a scene, defined in world coordinates, onto a specific area of the display screen, defined in device coordinates. The selected world-coordinate area is called the window, while the area on the screen where it is displayed is called the viewport.

In simple words, the window decides which part of the scene we want to see, and the viewport decides where and how large that part will appear on the screen. The transformation converts the coordinates of points from the window range into the corresponding viewport range.

4.2 Window and Viewport

  • Window: A rectangular area in world coordinates that selects the portion of the scene to be displayed.
  • Viewport: A rectangular area on the display device where the selected window contents are shown.

The window and viewport can have different sizes and positions. The transformation scales and shifts the selected scene so that it fits into the viewport.

4.3 Window-to-Viewport Transformation Formula

Let the window boundaries be Xwmin, Xwmax, Ywmin and Ywmax. Let the viewport boundaries be Xvmin, Xvmax, Yvmin and Yvmax.

Scaling factors

Sx = (Xvmax − Xvmin) / (Xwmax − Xwmin)

Sy = (Yvmax − Yvmin) / (Ywmax − Ywmin)

Coordinate transformation

Xv = Xvmin + (Xw − Xwmin) × Sx

Yv = Yvmin + (Yw − Ywmin) × Sy

(Xw, Yw) represents a point in world coordinates, and (Xv, Yv) represents its corresponding point in viewport coordinates.

4.4 Steps Involved

  1. Define the rectangular window in world coordinates.
  2. Define the viewport on the display screen.
  3. Calculate the horizontal and vertical scaling factors, Sx and Sy.
  4. Apply the coordinate transformation formulas to map each point from the window to the viewport.

4.5 Solved Numerical Example

Suppose the window is X: 0 to 100 and Y: 0 to 100. The viewport is X: 200 to 400 and Y: 100 to 300. Find the viewport coordinates of the world point (50, 50).

Step 1: Calculate scaling factors

Sx = (400 − 200) / (100 − 0) = 200 / 100 = 2

Sy = (300 − 100) / (100 − 0) = 200 / 100 = 2

Step 2: Convert the point (50, 50)

Xv = 200 + (50 − 0) × 2 = 300

Yv = 100 + (50 − 0) × 2 = 200

Final viewport point = (300, 200)

4.6 Importance

  • Displays a selected portion of a large scene on the screen.
  • Allows the same scene to be displayed in viewports of different sizes and positions.
  • Converts world-coordinate positions into display-coordinate positions.
  • Helps fit graphical scenes into a required screen area.

Exam answer (5 marks)

Window-to-viewport transformation is the process of converting a selected rectangular area of a scene from world coordinates into a rectangular area on the display screen. The selected area in world coordinates is called the window, and the display area is called the viewport. First, the horizontal and vertical scaling factors are calculated as Sx = (Xvmax − Xvmin)/(Xwmax − Xwmin) and Sy = (Yvmax − Yvmin)/(Ywmax − Ywmin). Then each point is mapped using Xv = Xvmin + (Xw − Xwmin) × Sx and Yv = Yvmin + (Yw − Ywmin) × Sy. This allows the selected scene to be positioned and resized to fit the required display area.

5Topic 5 of 5EfficiencyBLACK PRIORITY

Why BLACK? No standalone MCA question titled Efficiency is recorded; it is covered as part of the official syllabus.

5.1 Meaning

In computer graphics, efficiency of geometric transformation refers to performing operations such as translation, scaling, rotation, reflection and shearing with minimum computational effort and time. It is especially important when a graphical object contains many points or when transformations must be performed repeatedly.

A transformation may need to be applied to every vertex of an object. Therefore, reducing repeated calculations can improve the overall speed of a graphics system.

5.2 Use of Matrix Representation

Homogeneous coordinates represent 2D points using a 3 × 3 matrix. Translation, scaling, rotation and other transformations can then be represented in a common matrix form.

When several transformations are required, their matrices can be multiplied to create a single composite transformation matrix. The resulting matrix is then applied to each point, rather than applying each separate transformation one by one.

Without combining transformations

P' = T₃ × (T₂ × (T₁ × P))

Using a composite matrix

T = T₃ × T₂ × T₁

P' = T × P

5.3 How Efficiency Is Improved

  • Combine transformations: Multiply individual matrices once to form a composite matrix.
  • Reuse the composite matrix: Apply the combined matrix to all points of the object.
  • Avoid repeated calculations: Do not separately recalculate the same transformation sequence for every point.
  • Use suitable operations: Choose the required transformation directly and avoid unnecessary operations.

5.4 Example

Suppose an object has many vertices and each vertex must first be translated and then scaled.

Separate method: Apply the translation matrix to every vertex, then apply the scaling matrix to every resulting point.

Composite method: First calculate the combined matrix S × T. Then apply this single matrix to each original vertex.

The composite method reduces repeated matrix operations for the same sequence of transformations, particularly when the object has many vertices.

5.5 Important Point

Matrix multiplication used to prepare a composite transformation also requires computation. Its benefit is greatest when the same transformation sequence is applied to many points. The order of the matrices must still be correct because matrix multiplication is generally not commutative.

Exam answer (5 marks)

Efficiency in 2D geometric transformation means performing transformations with minimum computational time and effort. It is important when an object contains many points or when transformations are repeated. Homogeneous coordinates allow transformations to be represented using 3 × 3 matrices. Multiple transformations can be combined by multiplying their matrices to form a composite transformation matrix. This matrix can then be applied to each point of the object, reducing repeated calculations. Thus, matrix representation and composite transformations help improve the efficiency of geometric transformations.
