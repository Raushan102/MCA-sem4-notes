1Topic 1 of 5Input DevicesYELLOW PRIORITY

Why YELLOW? Related evidence: the older MCA paper (CS-DE-21) asks about GUI and input devices. No standalone MCA question on logical input devices is recorded.

1.1 Meaning of Input Devices in Interactive Graphics

In interactive computer graphics, input devices allow a user to provide graphical information to an application. The input may be a screen position, a sequence of positions, text, a numerical value, a menu selection or the identity of a displayed object.

Graphics systems classify input by the kind of information returned to the application. These are called logical input-device classes. A physical device such as a mouse may support more than one class.

1.2 Six Logical Input-Device Classes

Logical deviceWhat it providesExample / use
LocatorOne coordinate position (x, y).Mouse or digitizer stylus used to place a point.
StrokeA sequence of coordinate positions.Dragging a mouse to draw a freehand line.
StringA sequence of characters.Keyboard input for entering a label.
ValuatorA single numerical value.Slider or dial used to set an object’s size.
ChoiceOne option from a set of options.Selecting a tool from a menu.
PickThe identity of a displayed object or component.Clicking a particular object to select it.

1.3 Physical Device vs Logical Device

A physical device is the actual hardware, such as a mouse, keyboard or tablet. A logical device describes the type of information that the graphics application receives. For example, a mouse can act as a locator when it returns one position, or as a stroke device when it returns a sequence of positions while being dragged.

Exam answer (5 marks)

Input devices in interactive computer graphics are used to enter graphical information into an application. They are classified into six logical types: locator, stroke, string, valuator, choice and pick. A locator returns one coordinate position, a stroke returns a sequence of positions, a string returns characters, a valuator returns a numerical value, a choice selects one option from a set, and a pick identifies a displayed object. A single physical device may perform more than one logical input function.

2Topic 2 of 5Interaction Techniques and Interaction TasksRED PRIORITY

Why RED? Direct evidence: MCA 2022–24 (CCMCA403) records “interaction techniques and tasks” as a Unit III question.

2.1 Meaning of Interaction

Interaction is the communication between a user and a computer graphics application. The user gives input through a device, and the application responds by displaying or changing graphical information.

2.2 Interaction Technique

An interaction technique is a method through which a user performs an action and communicates with an application. It is a practical way of using an input device or interface to provide information or issue a command.

Examples:

  • Menu selection: choosing a command or tool from a displayed menu.
  • Pointing and clicking: using a pointer to indicate an item or position.
  • Dragging: holding an item with the pointer and moving it to another position.
  • Command-based interaction: typing a command using the keyboard.
  • Form filling: entering information into fields displayed on the screen.

2.3 Interaction Task

An interaction task is the unit of information or action that the user wants to provide to the application. It describes what the user wants to accomplish, rather than the particular method used.

For example, when a user wants to choose a drawing tool, the task is selection. The user may perform it by clicking a menu item, pressing a keyboard shortcut, or typing a command.

2.4 Difference Between Interaction Technique and Interaction Task

Interaction techniqueInteraction task
Describes how the user provides input.Describes what information or action the user wants to provide.
It is the method used to perform an action.It is the goal or unit of information being entered.
Example: clicking a menu item.Example: selecting a drawing tool.

2.5 Relationship Between Device, Technique and Task

A user performs an interaction task by using an interaction technique, usually through an input device. The same task may be performed using different techniques, and the same device may support different tasks.

Input Device → Interaction Technique → Interaction Task

Example: Mouse → Click a menu item → Select a drawing tool

Exam answer (5 marks)

Interaction in computer graphics is the communication between a user and a graphics application. An interaction technique is the method used by the user to provide input, such as menu selection, pointing and clicking, dragging, command entry or form filling. An interaction task is the unit of information or action that the user wants to provide, such as selecting an object or entering a value. Thus, a task describes what the user wants to do, while a technique describes how the user performs it. For example, selecting a drawing tool is an interaction task, while clicking its menu item is an interaction technique.

3Topic 3 of 5Interaction HardwareBLACK PRIORITY

Why BLACK? No direct PYQ identified in the checked papers; this topic is syllabus-based.

3.1 Meaning of Interaction Hardware

Interaction hardware refers to the physical devices through which a user communicates with a computer graphics system. These devices help the user enter commands, control graphical objects, provide positions or values, and receive visual or other feedback.

3.2 Input Hardware

Input hardware is used to send information or instructions to the graphics system.

DeviceUse in computer graphics
KeyboardEnters text, numeric values, commands and shortcuts.
MouseControls the pointer; selects, points to and drags graphical objects.
TrackballMoves the pointer by rotating a ball with the fingers.
JoystickControls direction and movement, especially in games and simulations.
Graphics tablet / DigitizerUses a stylus or puck to enter drawings and precise coordinates.
Touch screen / Touch panelAccepts input when the user touches a displayed item or position.
Light penHistorically used to point to or draw directly on a CRT display.
Data gloveCaptures hand and finger movements for gesture-based or virtual-reality interaction.
Spaceball / 3D controllerProvides control over movement and rotation in three-dimensional applications.
Microphone / Voice inputAccepts spoken commands or other audio input.

3.3 Output and Feedback Hardware

Output hardware presents the computer's response to the user. In an interactive graphics system, feedback helps the user understand the result of an action.

  • Monitor / Display: shows images, menus, pointers and changes to graphical objects.
  • Projector: displays graphics on a larger surface for group viewing.
  • Audio output: provides sound signals or alerts in response to user actions.
  • Haptic device: provides physical feedback, such as vibration or force, in supported interactive systems.

3.4 Why Interaction Hardware Is Needed

  • To enter commands and data into a graphics application.
  • To select, position and manipulate graphical objects.
  • To support accurate drawing and 3D navigation.
  • To provide visual, audio or physical feedback to the user.
Basic interaction flow

User → Input hardware → Graphics system → Output / feedback hardware → User

Exam answer (5 marks)

Interaction hardware consists of the physical devices used by a user to communicate with a computer graphics system. Input devices such as the keyboard, mouse, trackball, joystick, graphics tablet, touch screen and data glove are used to enter commands, select objects and control graphical operations. Output and feedback devices such as monitors, projectors, speakers and haptic devices present the system's response. Interaction hardware makes it possible to enter information, manipulate graphical objects and receive feedback during interactive graphics operations.

4Topic 4 of 5Basic Interaction TasksYELLOW PRIORITY

Why YELLOW? Related evidence: covered under the broader MCA 2022–24 topic “interaction techniques and tasks”; no standalone question is recorded.

4.1 Meaning

A basic interaction task is a fundamental action through which a user supplies information to a computer graphics application. These tasks are the building blocks used to create and manipulate graphical objects.

4.2 Common Basic Interaction Tasks

TaskMeaningExample
SelectionChoosing an object or item from several available options.Selecting a circle from a drawing.
PositioningSpecifying the location of an object or point.Placing a rectangle at a chosen position.
OrientationSpecifying the direction or rotation of an object.Rotating a line or shape to a required angle.
PathSpecifying a sequence of positions that define a route or curve.Drawing a freehand curve with a mouse or stylus.
QuantificationEntering a numerical value or quantity.Setting the width of a rectangle to 100 units.
TextEntering a sequence of characters.Adding a label to a diagram.

4.3 How Basic Tasks Are Performed

  • Selection: point to an item and choose it using a click, key or menu command.
  • Positioning: indicate a coordinate using a pointing device or enter coordinate values.
  • Orientation: rotate or specify an angle using a pointer, controller or numeric input.
  • Path: move a pointing device along the desired route to define a sequence of points.
  • Quantification: enter a value using a keyboard, slider or other valuator control.
  • Text: type the required characters using a keyboard or another text-entry method.

4.4 Importance

  • They provide the basic operations needed to interact with graphical objects.
  • They allow users to create, select, locate and modify objects.
  • They are combined to perform more complex graphical operations.
Example: Creating and placing a rectangle

Selection (choose rectangle tool) → Positioning (specify its location) → Quantification (enter width and height) → Orientation (rotate it, if required)

Exam answer (5 marks)

Basic interaction tasks are fundamental actions through which a user provides information to a computer graphics system. Common tasks include selection, positioning, orientation, path specification, quantification and text entry. Selection chooses an object, positioning specifies its location, orientation defines its direction, path specifies a sequence of points, quantification enters numerical values, and text entry supplies characters. These tasks form the foundation for creating and manipulating graphical objects in interactive graphics applications.

5Topic 5 of 5Composite Interaction TasksRED PRIORITY

Why RED? Direct evidence: MCA 2022–24 (CCMCA403) records “composite interaction tasks” as a Unit III question.

5.1 Meaning

A composite interaction task is an operation formed by combining two or more basic interaction tasks to achieve a more complete user goal. Instead of performing only one simple action, the user carries out a sequence or combination of actions.

5.2 Examples of Composite Interaction Tasks

Composite taskBasic tasks involvedExample
Drawing a rectangleSelection + positioning + quantificationSelect the rectangle tool, specify a starting point, then enter or indicate its width and height.
Moving an objectSelection + positioningSelect a shape and place it at a new location.
Rotating an objectSelection + orientationSelect an object and specify its rotation angle.
Drawing a labelled diagramSelection + positioning + path + textChoose drawing tools, create shapes and lines, position them, and add labels.
Resizing an objectSelection + quantification / positioningSelect a shape and change its dimensions using handles or numerical values.

5.3 How Composite Tasks Work

A composite task combines basic tasks in a meaningful order. The application may guide the user through several steps and provide feedback after each step.

Example: Moving a graphical object

1. Selection — choose the object.

2. Positioning — specify its new location.

3. Feedback — the application displays the object at the new position.

5.4 Importance

  • They allow users to perform practical operations using simple building blocks.
  • They make complex graphical operations easier to understand and perform.
  • They combine multiple input actions into one meaningful goal.
  • They are commonly used in drawing, CAD, image editing and other interactive graphics applications.

Exam answer (5 marks)

Composite interaction tasks are operations created by combining two or more basic interaction tasks to achieve a complete goal in a graphics application. For example, moving an object combines selection and positioning. Rotating an object combines selection and orientation. Drawing a rectangle may involve selecting a tool, specifying its position and entering its dimensions. Thus, composite tasks use basic tasks such as selection, positioning, orientation, path specification, quantification and text entry together to perform more meaningful graphical operations.
