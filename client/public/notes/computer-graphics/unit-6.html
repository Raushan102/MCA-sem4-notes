Why RED? The MCA 2022–24 paper includes a question on different types of projections. This is direct topic-level PYQ evidence.

1.1 Meaning of Projection

Projection is the process of representing a three-dimensional (3D) object on a two-dimensional (2D) viewing surface, such as a computer screen or a sheet of paper. It converts the 3D coordinates of an object into 2D coordinates so that the object can be displayed or drawn.

Since a screen is flat but objects in the real world have width, height and depth, projection provides a way to show 3D objects on a 2D surface. The appearance of the object depends on the type of projection used.

1.2 Basic Elements of Projection

  • Object: The 3D model or scene that must be displayed.
  • Projection plane: The flat surface on which the 3D object is projected.
  • Projectors: Imaginary straight lines drawn from points on the object towards the projection plane.
  • Centre of projection: The point from which projectors originate in perspective projection. In parallel projection, the projectors are parallel and meet at an imaginary point at infinity.

1.3 Types of Projection

In computer graphics, projections are broadly classified into two main categories:

Main classification

3D Projection

├── Parallel Projection

└── Perspective Projection

1.4 Parallel Projection

Parallel projection is a method in which all projectors are parallel to one another. The projected size of an object does not become smaller merely because the object is farther away from the viewer. It is useful in technical and engineering drawings where measurements and proportions need to be represented clearly.

Parallel projection is commonly divided into the following types:

  • Orthographic projection: The projectors are perpendicular (at 90°) to the projection plane. It is used to obtain front, top and side views of an object.
  • Oblique projection: The projectors meet the projection plane at an angle other than 90°. One face can be shown in its true shape while depth is represented at an angle.

1.5 Perspective Projection

Perspective projection is a method in which all projectors pass through a single fixed point called the centre of projection. Objects that are farther away from the viewer appear smaller, while nearer objects appear larger. This creates a realistic sense of depth, similar to how humans see objects.

Perspective projection is commonly classified according to the number of vanishing points:

  • One-point perspective: One set of parallel lines appears to meet at one vanishing point.
  • Two-point perspective: Two sets of parallel lines appear to meet at two vanishing points.
  • Three-point perspective: Three sets of parallel lines appear to meet at three vanishing points.

1.7 Applications of Projection

  • Displaying 3D models on 2D computer screens.
  • Creating realistic scenes in animation and games.
  • Preparing engineering and architectural drawings.
  • Representing depth and spatial relationships in computer graphics.

Exam answer (5 marks)

Projection is the process of converting a three-dimensional object into a two-dimensional representation on a projection plane. It is used to display 3D scenes on flat screens or paper. The two main types are parallel projection and perspective projection. In parallel projection, all projectors are parallel; its important types are orthographic and oblique projection. In perspective projection, all projectors pass through a common centre of projection, and distant objects appear smaller than nearby objects. Parallel projection is mainly used for technical drawings, whereas perspective projection is used to create realistic views.

2.1 Meaning

Specifying an arbitrary 3D view means defining the position and orientation of a viewer or camera so that a 3D scene can be viewed from any desired direction. Instead of viewing an object only from the front, top or side, we can choose a camera position and viewing direction to see the scene from a suitable angle.

To create this view, the graphics system needs information about where the viewer is located, which direction the viewer is looking, and which direction should appear as the upward direction on the screen. This information is used to establish a viewing coordinate system.

2.2 Main Parameters Required

  • View reference point (VRP): A point that specifies the position or reference location of the viewing coordinate system in the world-coordinate scene.
  • View plane normal (VPN): A vector perpendicular to the viewing plane. It establishes the direction of the viewing plane and helps define the viewing orientation.
  • View-up vector (VUP): A vector that indicates the upward direction for the view. It helps determine how the scene is oriented on the screen and prevents the view from appearing tilted unexpectedly.
  • View window: The region of the viewing plane selected for display. It determines which part of the scene is included in the view.

2.3 Viewing Coordinate System

After the viewing parameters are specified, the system establishes three perpendicular viewing axes, commonly represented as u, v and n. These axes describe the horizontal, vertical and viewing directions of the camera.

  • u-axis: The horizontal direction of the viewing coordinate system.
  • v-axis: The vertical or view-up direction.
  • n-axis: The direction perpendicular to the viewing plane, defining the viewing orientation.

The viewing coordinate system provides a convenient reference frame for transforming objects from world coordinates into view coordinates before projection.

2.4 Steps to Specify an Arbitrary 3D View

  1. Choose the view reference point to establish the viewing reference location.
  2. Specify the view plane normal to define the orientation of the viewing plane.
  3. Specify the view-up vector to determine the upward direction on the screen.
  4. Use these parameters to establish the viewing axes u, v and n.
  5. Define the view window to select the required portion of the scene.
  6. Transform the scene into viewing coordinates and then apply the required projection.

2.5 Why These Parameters Are Important

The view reference point determines the reference location, while the view plane normal determines the direction in which the viewing plane is oriented. The view-up vector determines how the scene is rotated within the view. Together, these parameters allow the camera to be placed and oriented flexibly.

For example, when viewing a building from an elevated corner, the camera position and viewing direction are chosen so that the front, side and top portions can be seen together. The view-up vector ensures that the building appears upright in the final image.

2.6 Applications

  • Changing camera angles in 3D games and animation.
  • Viewing 3D models from different directions in CAD software.
  • Choosing suitable camera positions in architectural visualisation.
  • Inspecting objects in scientific and engineering simulations.

Exam answer (5 marks)

Specifying an arbitrary 3D view is the process of defining the position and orientation of a viewer or camera to observe a 3D scene from a desired direction. The main parameters are the view reference point (VRP), view plane normal (VPN), view-up vector (VUP) and view window. These parameters are used to establish the viewing coordinate axes u, v and n. The scene is then transformed from world coordinates into viewing coordinates, after which the required projection is applied. This method allows a 3D object to be viewed from different positions and angles.

3Topic 3 of 6Examples of 3D ViewingBLACK PRIORITY

Why BLACK? No direct or clearly related standalone PYQ for this subtopic is confirmed in the available exam evidence.

3.1 Meaning

3D viewing is the process of selecting a viewpoint and displaying a three-dimensional scene on a two-dimensional screen. The same object can look different when viewed from different positions and directions. By changing the camera position, viewing direction and projection method, we can observe different sides and details of the object.

For example, a building can be viewed from the front to see its entrance, from above to see its roof, or from a corner to see two sides together. These are different views of the same 3D object.

3.2 Front View

A front view is obtained when the viewer looks directly towards the front face of an object. It shows the width and height of the object clearly, but depth is not directly visible in the view.

Example: Looking straight at the front wall of a building or the front face of a box.

3.3 Top View

A top view is obtained when the viewer looks down at the object from above. It is useful for observing the layout, length and width of an object or scene. The height dimension is not directly represented in this view.

Example: Looking down at the roof of a house or the arrangement of furniture in a room.

3.4 Side View

A side view is obtained when the viewer looks at an object from its left or right side. It helps show the object's depth and height.

Example: Viewing a car from its side to observe its length, height and side profile.

3.5 Axonometric or Isometric View

An axonometric view is a type of parallel projection in which more than one face of an object can be seen in the same view. In an isometric view, the three principal axes are equally inclined to the projection plane, so the three directions are represented with equal scale.

Example: A cube shown with its front, side and top faces visible together in a technical drawing.

3.6 Perspective View

A perspective view represents an object in a way that resembles human vision. Objects farther from the viewer appear smaller, and parallel lines may appear to meet at vanishing points. This gives the scene a realistic sense of depth.

Example: A road or railway track appears to become narrower as it extends towards the horizon.

3.8 Importance of Different 3D Views

  • Different views reveal different details of the same object.
  • Front, top and side views are useful in technical and engineering drawings.
  • Isometric views help understand the overall shape of an object.
  • Perspective views are useful for realistic scenes in games, animation and architectural visualisation.

Exam answer (5 marks)

3D viewing is the process of displaying a three-dimensional object or scene from a selected viewpoint on a two-dimensional screen. Common examples include front view, top view and side view, which show different faces or dimensions of an object. An isometric view displays several faces together using equal scale along the three principal axes. A perspective view creates a realistic appearance in which distant objects look smaller than nearby objects. Different views are selected according to the details that need to be observed or displayed.

4Topic 4 of 6The Mathematics of Planar Geometric ProjectionsBLACK PRIORITY

Why BLACK? No direct or clearly related standalone PYQ for this subtopic is confirmed in the available exam evidence.

4.1 Meaning

Planar geometric projection is the mathematical process of mapping points of a 3D object onto a flat 2D plane. The projected point is found where a projection line (projector) through the original 3D point meets the projection plane.

The calculation depends on the position of the projection plane and the direction of the projectors. The two main mathematical cases are parallel projection and perspective projection.

4.2 Mathematical Elements

  • 3D point: P(x, y, z), a point on the object.
  • Projection plane: The flat plane receiving the image. For the examples below, use the XY-plane, whose equation is z = 0.
  • Projector: A straight line passing through P and its projected point P′.
  • Projected point: P′(x′, y′, z′), the intersection of the projector and the projection plane.
  • Centre of projection (COP): A finite point through which perspective projectors pass.
  • Direction of projection: The common direction of parallel projectors.
Projection plane used in the derivations

XY-plane: z = 0

Therefore, every projected point on this plane has z′ = 0.

4.3 Mathematics of Parallel Projection

In parallel projection, all projectors have the same direction. Let the direction vector be D = (l, m, n), where n ≠ 0. A projector through P(x, y, z) can be written using a parameter t:

Line through P in direction D

x′ = x + tl

y′ = y + tm

z′ = z + tn

Because the projected point lies on the XY-plane, z′ = 0. Thus:

Find the parameter

0 = z + tn

t = −z / n

Substituting this value into the x and y equations gives the general parallel projection onto the XY-plane:

Parallel projection equations

x′ = x − (l × z) / n

y′ = y − (m × z) / n

z′ = 0

4.4 Orthographic Projection

Orthographic projection is a special type of parallel projection in which the projectors are perpendicular to the projection plane. For projection onto the XY-plane, choose D = (0, 0, −1). This means l = 0, m = 0 and n = −1.

Orthographic projection

x′ = x

y′ = y

z′ = 0

So, the x- and y-coordinates remain unchanged, while the z-coordinate is removed. This produces a flat view of the object on the XY-plane.

4.5 Mathematics of Perspective Projection

In perspective projection, all projectors pass through one finite centre of projection. For a simple derivation, take the centre of projection as C = (0, 0, −d), the projection plane as z = 0, and an object point as P = (x, y, z).

The line from C to P is described by:

Projector line

Q(t) = C + t(P − C)

x′ = tx

y′ = ty

z′ = −d + t(z + d)

At the projection plane, z′ = 0. Therefore:

Find t

0 = −d + t(z + d)

t = d / (z + d)

Substituting t gives the perspective projection equations:

Perspective projection onto z = 0

x′ = (d × x) / (z + d)

y′ = (d × y) / (z + d)

z′ = 0

Here, d is the distance from the centre of projection to the projection plane. The denominator makes the projected size depend on the point's depth, producing the perspective effect. These equations use the coordinate convention stated above; other textbooks may choose a different axis direction or projection-plane position.

4.6 Homogeneous Matrix Representation

Projection equations can also be represented using matrices. For the orthographic projection onto the XY-plane, use the following 4 × 4 matrix with a point written as a column vector:

Orthographic projection matrix

[ x′ ] [ 1 0 0 0 ] [ x ]

[ y′ ] = [ 0 1 0 0 ] [ y ]

[ z′ ] [ 0 0 0 0 ] [ z ]

[ 1 ] [ 0 0 0 1 ] [ 1 ]

For the perspective setup defined in Section 4.5, the projective matrix produces homogeneous coordinates [dx, dy, 0, z + d]. Divide the first three coordinates by the fourth coordinate (the homogeneous w value) to obtain the ordinary projected coordinates.

Perspective homogeneous form

[ X ] [ d 0 0 0 ] [ x ]

[ Y ] = [ 0 d 0 0 ] [ y ]

[ Z ] [ 0 0 0 0 ] [ z ]

[ W ] [ 0 0 1 d ] [ 1 ]

Then: x′ = X/W, y′ = Y/W, z′ = Z/W.

4.7 Worked Example — Orthographic Projection

Question: Project the 3D point P(4, 3, 5) orthographically onto the XY-plane.

Solution: For orthographic projection onto the XY-plane, x′ = x, y′ = y and z′ = 0.

Substitute the point

x′ = 4

y′ = 3

z′ = 0

Projected point = P′(4, 3, 0)

4.8 Difference Between Parallel and Perspective Projection

Parallel projectionPerspective projection
Projectors are parallel.Projectors meet at a finite centre of projection.
Projected size does not reduce with depth in the same way.Distant objects generally appear smaller.
Useful for technical and engineering views.Useful for realistic visual scenes.
Includes orthographic and oblique projection.Includes one-point, two-point and three-point perspective.

Exam answer (5 marks)

Planar geometric projection is the mathematical mapping of a 3D object onto a 2D plane. It is performed by drawing projectors through points of the object and finding where they intersect the projection plane. In parallel projection, the projectors are parallel and the projected coordinates are obtained using a common direction vector. Orthographic projection is the special case in which the projectors are perpendicular to the plane. In perspective projection, the projectors pass through a finite centre of projection, and the projected coordinates are calculated using ratios involving depth. Both types can be represented mathematically using transformation matrices.

5Topic 5 of 6Implementing Planar Geometric ProjectionBLACK PRIORITY

Why BLACK? No direct or clearly related standalone PYQ for this subtopic is confirmed in the available exam evidence.

5.1 Meaning

Implementing planar geometric projection means applying the mathematical projection rules to the coordinates of a 3D object so that its 2D image can be displayed on a projection plane. In a graphics system, this is carried out through coordinate calculations or matrix operations.

The same basic process is used for parallel and perspective projection. The main difference is how the projected coordinates are calculated.

5.2 General Steps of Implementation

  1. Define the 3D object: Store the coordinates of its vertices as (x, y, z).
  2. Choose the projection type: Select parallel projection or perspective projection.
  3. Specify the projection plane: Define its position and orientation. For a simple example, use the XY-plane, z = 0.
  4. Specify projection parameters: For parallel projection, provide the direction vector. For perspective projection, provide the centre of projection.
  5. Calculate projected coordinates: Find where each projector intersects the projection plane.
  6. Apply the projection matrix if used: Multiply the point's coordinate vector by the appropriate matrix.
  7. Perform homogeneous division when required: In perspective projection, divide X, Y and Z by W to obtain ordinary coordinates.
  8. Display the 2D result: Use the projected vertices to draw the object's edges or surfaces.

5.3 Implementing Parallel Projection

For projection onto the XY-plane, let the parallel direction vector be D = (l, m, n), where n ≠ 0. For each object point P(x, y, z), calculate:

Parallel projection equations

x′ = x − (l × z) / n

y′ = y − (m × z) / n

z′ = 0

These equations are applied to every vertex of the object. If the direction is perpendicular to the XY-plane, the projection becomes orthographic: x′ = x, y′ = y and z′ = 0.

5.4 Implementing Perspective Projection

For a simple perspective setup, place the projection plane at z = 0 and the centre of projection at C = (0, 0, −d). For each point P(x, y, z), calculate:

Perspective projection equations

x′ = (d × x) / (z + d)

y′ = (d × y) / (z + d)

z′ = 0

The value of d and the coordinate convention must remain consistent throughout the calculation. The denominator (z + d) must not be zero. In a matrix-based implementation, the projected point is first represented by homogeneous coordinates (X, Y, Z, W), and then converted:

Homogeneous division

x′ = X / W

y′ = Y / W

z′ = Z / W

5.5 Worked Example — Parallel Projection

Question: Project P(4, 3, 2) onto the XY-plane using the parallel direction D = (1, 1, −2).

Step 1: Identify l = 1, m = 1, n = −2 and z = 2.

Step 2: Apply the parallel projection equations.

Calculation

x′ = 4 − (1 × 2)/(−2) = 5

y′ = 3 − (1 × 2)/(−2) = 4

z′ = 0

Projected point = P′(5, 4, 0)

5.6 Worked Example — Perspective Projection

Question: Project P(2, 4, 5) onto z = 0 when the centre of projection is C = (0, 0, −5).

Here, d = 5. Apply the perspective equations:

Calculation

x′ = (5 × 2)/(5 + 5) = 10/10 = 1

y′ = (5 × 4)/(5 + 5) = 20/10 = 2

z′ = 0

Projected point = P′(1, 2, 0)

5.7 Simple Implementation Logic

The following pseudocode describes the main processing performed for each vertex. It is a general algorithm, not a specific programming-language implementation.

For each vertex P(x, y, z):
    If projection is parallel:
        Calculate x' and y' using the direction vector
    Otherwise, if projection is perspective:
        Calculate X, Y, Z and W using the projection matrix
        If W is not zero, divide X, Y and Z by W
    Store the projected point (x', y', z')
Draw the object using the projected vertices

5.8 Important Implementation Points

  • Use the same coordinate system and projection-plane definition for all points.
  • For parallel projection onto z = 0, the direction vector must have n ≠ 0; otherwise, the projector does not meet the plane at a unique point using these equations.
  • For perspective projection, check that the homogeneous coordinate W is not zero before dividing.
  • Apply the projection to every vertex so that the shape's edges can be reconstructed in the 2D view.
  • After projection, the 2D coordinates may need to be mapped to screen or viewport coordinates for display.

Exam answer (5 marks)

Planar geometric projection is implemented by converting the coordinates of a 3D object's points into coordinates on a 2D projection plane. First, the object and projection plane are defined. Next, the projection type and its parameters are selected. In parallel projection, the common direction vector is used to calculate the intersection of each projector with the plane. In perspective projection, the centre of projection is used and the projected coordinates are obtained by homogeneous division. The resulting 2D points are then used to display the object's edges and surfaces.

6.1 Meaning of Coordinate Systems

A coordinate system is a reference framework used to describe the position of points in space. In 3D computer graphics, a point is commonly represented by three coordinates: (x, y, z).

Different coordinate systems are used at different stages of graphics processing. They help describe an object's own position, place it in a scene, define the camera view, perform projection and finally display the image on a screen.

6.2 Main Coordinate Systems in 3D Graphics

1. Object (Model) Coordinate System

This is the local coordinate system in which an individual object is created. The object's vertices are defined relative to its own origin. For example, a cube may be modelled around the point (0, 0, 0), before being placed in a larger scene.

2. World Coordinate System

The world coordinate system is the common reference system for the complete 3D scene. Objects are positioned, rotated and scaled within this shared space. It allows several objects to be arranged in relation to one another.

3. Viewing (Camera) Coordinate System

This coordinate system is defined with respect to the camera or viewer. The camera position and orientation determine how the world is seen. The scene is transformed from world coordinates into viewing coordinates before projection.

4. Projection Coordinates

Projection converts the 3D view into a representation suitable for a 2D projection plane. The mathematical operation depends on whether parallel or perspective projection is selected.

5. Normalized Device Coordinates

After projection and the required homogeneous-coordinate conversion, the visible image can be mapped into a standard normalized viewing region. This gives a device-independent representation before mapping to a particular display.

6. Device (Screen) Coordinate System

Device coordinates identify positions on the actual output device, such as a monitor. The normalized image is mapped to screen or viewport coordinates, commonly measured in pixels.

6.3 Coordinate Transformation Pipeline

A 3D graphics system converts object coordinates through a sequence of coordinate systems before displaying the final image.

General 3D viewing pipeline

Object / Model Coordinates

↓ Model Transformation

World Coordinates

↓ Viewing (Camera) Transformation

Viewing Coordinates

↓ Projection Transformation

Projected / Normalized Device Coordinates

↓ Viewport Transformation

Device / Screen Coordinates

Each transformation changes the reference frame or representation of the points. The object itself does not need to be physically moved; its coordinates are mathematically converted.

6.4 Homogeneous Coordinates

Homogeneous coordinates are used to represent 3D points in a form that makes translation, rotation, scaling and other transformations convenient to combine using matrices.

3D point in homogeneous form

Cartesian point: P = (x, y, z)

Homogeneous point: P = (x, y, z, 1)

For a homogeneous point (X, Y, Z, W):

x = X/W, y = Y/W, z = Z/W

For ordinary 3D points, W is commonly 1 before projective transformations. After perspective projection, W may have another value and the coordinates are converted back by dividing by W, provided W is not zero.

6.5 Example — Moving a Point from Object to World Coordinates

Question: An object's point is P = (2, 1, 3). The object is translated by (5, 2, 1). Find the point in world coordinates, assuming no rotation or scaling.

Solution: Add the translation values to the corresponding coordinates.

Calculation

xw = 2 + 5 = 7

yw = 1 + 2 = 3

zw = 3 + 1 = 4

World coordinate point = (7, 3, 4)

6.6 Importance of Coordinate Systems

  • They provide a consistent way to represent positions in a 3D scene.
  • They allow objects to be modelled independently and then placed in a common world.
  • They define the camera's position and orientation for viewing.
  • They make projection and conversion to screen coordinates possible.
  • They help graphics systems support different output devices and viewport sizes.

Exam answer (5 marks)

Coordinate systems are reference frameworks used to specify the position of points in 3D space. In computer graphics, object coordinates describe an object's local geometry, world coordinates locate objects in the complete scene, and viewing coordinates describe the scene relative to the camera. Projection coordinates are produced when the 3D view is projected onto a 2D plane. Normalized device coordinates provide a standard representation, which is finally converted into device or screen coordinates for display. Transformations are used to convert points from one coordinate system to another.
